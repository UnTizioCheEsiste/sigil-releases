# Sigil releases

This repository hosts official compiled Sigil desktop releases for Windows x64. Application source is maintained in a separate private repository.

Download the latest stable installer from [GitHub Releases](https://github.com/UnTizioCheEsiste/sigil-releases/releases/latest). The primary asset is **Sigil-Windows-x64.exe**, with **Sigil-Windows-x64.exe.sha256** for SHA-256 verification. Installers include WebView2 and require no Node.js or Rust installation.

Stable download: https://github.com/UnTizioCheEsiste/sigil-releases/releases/latest/download/Sigil-Windows-x64.exe

Latest release metadata: https://api.github.com/repos/UnTizioCheEsiste/sigil-releases/releases/latest

No stable download is available until the first stable release is published. Prereleases are listed separately on the releases page.

The installer is currently unsigned. This repository contains no source code, credentials or committed installer binaries; downloads are GitHub Release assets.
